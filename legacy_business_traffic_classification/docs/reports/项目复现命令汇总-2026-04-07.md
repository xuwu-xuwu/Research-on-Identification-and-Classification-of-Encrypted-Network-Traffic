# 项目复现命令汇总（截至 2026-04-07）

本文档汇总当前项目主线、论文复现线和新增深度学习分支的关键复现命令。默认使用 `PowerShell`，默认在仓库根目录执行，除非命令块里明确切换到了其他目录。

## 1. 通用约定

### 1.1 先进入环境和项目根目录

```powershell
conda activate ai
Set-Location 'd:\Research on Identification and Classification of Encrypted Network Traffic'
```

### 1.2 说明

1. 本文档命令以“能复现当前仓库中的主要结果”为目标。
2. `TrafficFormer` 部分有些命令需要先切到 `src\reproduction\TrafficFormer` 目录执行。
3. 如果机器没有 `CUDA`，把命令里的 `--device cuda` 改成 `--device cpu` 或 `--device auto`。
4. 如果 `PowerShell` 多行续行不方便，也可以把命令改成一行执行。

## 2. 流级统计特征主线

## 4. `TrafficFormer` 论文复现

这一部分建议先切到 `TrafficFormer` 目录再执行。

### 4.1 切换到 `TrafficFormer` 目录

```powershell
Push-Location src\reproduction\TrafficFormer
```

### 4.2 检查环境

```powershell
python scripts\check_env.py
```

### 4.3 准备 `ISCX-VPN service` 数据

```powershell
python scripts\prepare_iscxvpn_data.py `
  --vpn_dir ..\..\..\data\VPN-PCAPs-02 `
  --output_dir data\iscxvpn_service
```

说明：

1. 该步骤会组织原始 `pcap`，并尽量切分为单流文件。
2. 若本机装有 `SplitCap.exe`、`tshark`、`editcap`，效果更完整。

### 4.4 生成 baseline 微调数据

```powershell
python scripts\generate_finetune_data.py `
  --splitcap_dir data\iscxvpn_service\splitcap `
  --output_dir data\iscxvpn_service\dataset `
  --max_samples 2000 `
  --start_index 28 `
  --seed 42
```

### 4.5 生成带 `RIFA` 的微调数据

```powershell
python scripts\generate_finetune_data.py `
  --splitcap_dir data\iscxvpn_service\splitcap `
  --output_dir data\iscxvpn_service\dataset `
  --max_samples 2000 `
  --start_index 28 `
  --train_augment_factor 5 `
  --seed 42
```

说明：

1. baseline 训练集对应 `train_base_dataset.tsv`
2. RIFA 训练集对应 `train_rifa_dataset.tsv`
3. 当前实际激活的 paper-style 训练文件是 `train_dataset.tsv`

### 4.6 下载预训练模型

```powershell
python scripts\download_pretrain_model.py
```

### 4.7 复现 TrafficFormer baseline fine-tuning

```powershell
python fine-tuning\run_classifier.py `
  --vocab_path models\encryptd_vocab.txt `
  --train_path data\iscxvpn_service\dataset\train_base_dataset.tsv `
  --dev_path data\iscxvpn_service\dataset\valid_dataset.tsv `
  --test_path data\iscxvpn_service\dataset\test_dataset.tsv `
  --pretrained_model_path models\pretrain_model.bin `
  --output_model_path models\finetuned_model.bin `
  --epochs_num 10 `
  --earlystop 4 `
  --batch_size 4 `
  --embedding word_pos_seg `
  --encoder transformer `
  --mask fully_visible `
  --seq_length 320 `
  --learning_rate 6e-5 `
  --config_path models\bert\base_config.json
```

### 4.8 复现 TrafficFormer + `RIFA`

```powershell
python fine-tuning\run_classifier.py `
  --vocab_path models\encryptd_vocab.txt `
  --train_path data\iscxvpn_service\dataset\train_dataset.tsv `
  --dev_path data\iscxvpn_service\dataset\valid_dataset.tsv `
  --test_path data\iscxvpn_service\dataset\test_dataset.tsv `
  --pretrained_model_path models\pretrain_model.bin `
  --output_model_path models\finetuned_model_rifa.bin `
  --epochs_num 10 `
  --earlystop 4 `
  --batch_size 4 `
  --embedding word_pos_seg `
  --encoder transformer `
  --mask fully_visible `
  --seq_length 320 `
  --learning_rate 6e-5 `
  --config_path models\bert\base_config.json
```

### 5.4 更强的 `BiLSTM` 版本（当前保留的 v2）

这是当前保留的更强版本，最终采用了 `BiLSTM-only + RIFA` 配置。

```powershell
python src\deep_learning\train_rifa_bilstm_transformer.py `
  --train-path src\reproduction\TrafficFormer\data\iscxvpn_service\dataset\train_rifa_dataset.tsv `
  --dev-path src\reproduction\TrafficFormer\data\iscxvpn_service\dataset\valid_dataset.tsv `
  --test-path src\reproduction\TrafficFormer\data\iscxvpn_service\dataset\test_dataset.tsv `
  --label-map-path src\reproduction\TrafficFormer\data\iscxvpn_service\dataset\label_map.json `

  --run-name rifa_bilstm_only_v2 `

  --embedding-dim 128 `
  --lstm-hidden-dim 160 `
  --lstm-layers 2 `
```

## 6. 当前最推荐的复现顺序

如果你现在只想最快把当前项目的关键成果复现出来，推荐按这个顺序跑：

1. 主线优化版  
   先跑 `src\teammate_optimized\train_final_optimized_v2.py`
2. `TrafficFormer + RIFA`  
   先完成 `TrafficFormer` 数据准备，再跑 `run_classifier.py` 或 wrapper
3. `TextCNN + RIFA`  
   作为自研轻量深度学习分支
4. `C-LSTM` 论文复现  
   先做 `prepare_dataset.py`，再跑 `train_c_lstm.py`

# Tools

Current helper scripts retained in this directory:

- `build_encryption_method_dataset.py`: first-pass encryption-method dataset builder from local PCAP files.
- `build_midterm_report_docx.py`: generates the current midterm report DOCX from Markdown and the template under `docs/templates/`.
- `build_detailed_design_docx.py`: generates the current detailed-design report DOCX from Markdown and the template under `docs/templates/`.
